# FTPデプロイスキル

このスキルは、変更されたファイルの確認、Gitコミット＆プッシュ、およびFTPサーバーへの差分ファイルデプロイのプロセスを自動化します。特にファイルの削除操作がある場合は慎重に確認を行います。

## エージェント（AI）向け実行手順

ユーザーからデプロイやFTP反映の要求があった場合、以下のステップを順に実行してください。

### ステップ 1: 変更内容の確認とユーザーへの確認
1. 対象のプロジェクトディレクトリ（例：`hanasakikashiten.com`, `Hanasaki-miyagawacho`, `Hanasaki-manjiro` など）内で `git status` および `git diff` を実行し、ローカルの変更を確認します。
2. 変更があったファイルの一覧と差分の概要を、わかりやすく**日本語でユーザーに提示**します。
   - **【最重要】ファイルの削除（Deleted）またはリネームによる旧ファイルの削除が含まれる場合は、太字や警告表示を用いて、本番サーバーから削除されるファイルを強調して提示してください。**
3. **実行の可否についてユーザーに明示的な確認**を求めます。
   > **確認用のメッセージ例：**
   > 以下の変更をコミットし、プッシュおよびFTPデプロイを実行しますか？
   > コミットメッセージを入力いただくか、デフォルト（例：「Update website content」）で進める場合はその旨をお知らせください。

### ステップ 2: Gitコミット＆プッシュ
1. 現在のアクティブなブランチ（`main` または `master`）を確認します。
2. 変更・追加されたファイルをインデックスに追加します：
   ```bash
   git add -A
   ```
3. ユーザーが指定したコミットメッセージ（または自動生成したメッセージ）でコミットします：
   ```bash
   git commit -m "コミットメッセージ"
   ```
4. リモートリポジトリにプッシュします（リモートが設定されている場合）：
   ```bash
   git push origin <ブランチ名>
   ```

### ステップ 3: FTP設定の確認
1. プロジェクトルートに設定ファイル `<プロジェクトディレクトリ>/.ftp_config.json` が存在するか確認します。
2. 存在しない場合：
   - ユーザーにFTP接続情報の設定が必要である旨を伝えます。
   - `<プロジェクトディレクトリ>/.ftp_config.json.template` を `<プロジェクトディレクトリ>/.ftp_config.json` にコピーし、ホスト・ユーザー名・パスワード等の情報を入力するよう案内します。
   - ユーザーの設定作業が完了するまで処理を一時停止し、作成されたことを確認してから次のステップに進みます。

### ステップ 4: FTPデプロイスクリプトの実行（削除確認の徹底）
1. 初回デプロイ時、あるいはサーバーのファイルがすでに最新状態（HEADと同じ）でファイルのアップロードをスキップしたい場合は、`--catchup` オプションを付けて実行し、サーバー上のデプロイ位置（コミットハッシュ）のみを更新させることができます：
   ```bash
   python3 .agents/skills/deploy-ftp/scripts/ftp_deploy.py --repo-path <プロジェクトディレクトリ> --catchup
   ```
2. 通常の差分デプロイの場合は、**まず最初に `--dry-run` を付与してスクリプトを実行し、反映内容をシミュレーションします：**
   ```bash
   python3 .agents/skills/deploy-ftp/scripts/ftp_deploy.py --repo-path <プロジェクトディレクトリ> --dry-run
   ```
3. **【削除安全確認】`--dry-run` の出力において「Files to delete」にファイルが1件以上含まれる場合：**
   - 削除されるファイル一覧をチャット上で箇条書きにし、**「⚠️警告：本番サーバーから以下のファイルを完全に削除します。実行してもよろしいですか？」**とユーザーに個別に再度確認をとってください。
   - ユーザーから「はい」「実行してください」等の明示的な同意を得るまで、デプロイの本実行（次の手順4）に進んではいけません。
4. ユーザーからの最終確認が得られたら、本番デプロイ（`--dry-run` なし）を実行します：
   ```bash
   python3 .agents/skills/deploy-ftp/scripts/ftp_deploy.py --repo-path <プロジェクトディレクトリ>
   ```
5. スクリプトの実行ログを監視します。
6. スクリプトが正常に完了したら、デプロイが成功したこと、およびFTPサーバー上の `.git-ftp-commit` ファイル（前回デプロイ時のコミットハッシュ記録）が更新されたことをユーザーに報告します。
7. エラーが発生した場合は、エラー詳細を報告し、対処方法を尋ねます。
